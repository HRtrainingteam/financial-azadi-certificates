# Financial Azadi Quiz Certificate Portal

The portal uses the Employee Code to find a participant locally from `data.js`.

Certificate rule:
- Exactly 8 marks → Achievement Certificate
- Less than 8 marks → Participation Certificate

Required Asset files:
- `Asset/certificate-template.png`
- `Asset/participation-template.png`

`data.js` contains the combined participant/winner data generated from the supplied Excel files.
